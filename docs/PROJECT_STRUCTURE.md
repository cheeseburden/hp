## Component Map — What Does What

### 🐍 Backend (FastAPI)

| File | Purpose | Real or Simulated |
|---|---|---|
| `main.py` | App startup — loads model, connects Kafka/ES/Vault, starts consumer | Real |
| `config.py` | Environment variables: `VAULT_ADDR`, `KAFKA_BOOTSTRAP_SERVERS`, etc. | Config |
| `schemas.py` | Pydantic models: `NetworkEvent`, `PredictionResult`, `PipelineStageResult` | Schemas |
| `inference.py` | Loads `.joblib` model, runs XGBoost + LightGBM ensemble predictions | **Real ML** |
| `threat_engine.py` | Orchestrates all 10 pipeline stages per event, updates global metrics | **Real** |
| `pipeline_stages.py` | Simulates stages 1-3 (Network, IDS, Beats), 6 (SOAR), 8-9 (Cred rotation/dist) | Simulated |
| `kafka_client.py` | Produces raw events to Kafka, consumes from `hpe-raw-events` topic | **Real** |
| `elastic_client.py` | Indexes audit logs and threats into Elasticsearch | **Real** |
| `vault_client.py` | Manages 200 user credentials in HashiCorp Vault KV, rotates on threat | **Real** |
| `vault_infra_client.py` | Infrastructure credential rotation (DB secrets engine + Kafka KV) | **Real** |
| `redis_client.py` | Cross-pod WebSocket broadcasting and caching | **Real** |
| `auth_admin.py` | JWT-based admin authentication | **Real** |
| `admin_store.py` | Alert and audit state management | Real |
| `drift_monitor.py` | Model drift detection background service | **Real** |
| `soar_email.py` | Email notifications for critical events | **Real** |
| `ws_manager.py` | Broadcasts pipeline results to all connected WebSocket clients | Real |

## API Endpoints Quick Reference

### REST

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Full health check (model, kafka, ES, vault) |
| `GET` | `/api/metrics` | Pipeline metrics (threats, latency, attack types) |
| `GET` | `/api/pipeline/status` | All 10 pipeline stages with real health status |
| `POST` | `/api/predict` | Process a single `NetworkEvent` through the pipeline |
| `GET` | `/api/vault/credentials` | Latest rotated user's masked credentials |
| `GET` | `/api/vault/users` | **All 200 users** masked credentials (filter: `?role=`, `?region=`) |
| `GET` | `/api/vault/users/{user_id}` | Single user's masked credentials |
| `GET` | `/api/sample-events` | Test events count |

### WebSocket

| Endpoint | Description |
|---|---|
| `WS /ws/simulate` | Streams test events through the full pipeline in real-time |

## Key Config (Environment Variables)

| Variable | Default | Where Used |
|---|---|---|
| `KAFKA_BOOTSTRAP_SERVERS` | `localhost:9094` | `kafka_client.py` |
| `ELASTICSEARCH_URL` | `http://localhost:9200` | `elastic_client.py` |
| `REDIS_URL` | `redis://redis:6379` | `redis_client.py`, `auth.py` |
| `VAULT_ADDR` | `http://localhost:8200` | `vault_client.py`, `vault_infra_client.py` |
| `VAULT_APPROLE_CREDS_FILE` | `/vault/data/.approle_credentials` | `vault_client.py` |
| `POSTGRES_URL` | `postgresql://localhost:5432/hpedb` | `db.py` |
| `MODEL_PATH` | `model_output/pipeline_artifacts_v2.joblib` | `inference.py` |
| `TEST_EVENTS_PATH` | `model_output/test_events.json` | `simulate.py` |
| `PROFILES_PATH` | `model_output/user_profiles.json` | `vault_client.py` |
| `ENABLE_AUTO_USER_ROTATION` | `false` | `config.py`, `threat_engine.py` |
| `PORTAL_ONLY_MODE` | `false` | `config.py` |
| `SOAR_EMAIL_ENABLED` | `false` | `config.py`, `soar_email.py` |

## Where to Make Common Changes

| I want to... | File(s) to edit |
|---|---|
| Add a new API endpoint | `backend/app/routes/` → create or modify route file, register in `main.py` |
| Change AI model behavior | `backend/app/inference.py`, retrain with `export_v2_model.py` |
| Modify threat scoring thresholds | `backend/app/config.py` → `THREAT_LEVELS` |
| Add a new pipeline stage | `backend/app/pipeline_stages.py` + `threat_engine.py` |
| Change Vault credential fields | `backend/app/vault_client.py` |
| Add admin authentication logic | `backend/app/auth_admin.py` |
| Modify admin dashboard features | `frontend/src/components/AdminConsole.jsx` |
| Change main dashboard layout | `frontend/src/components/AnalyticsDashboard.jsx` |
| Update 3D globe appearance | `frontend/src/components/ThreatGlobe.jsx` |
| Update CSS / colors / animations | `frontend/src/styles/index.css` |
| Add a new Docker service | `docker-compose.yml` or `docker-compose.portal.yml` |
| Configure Kubernetes deployment | `k8s/` manifests, `deploy.ps1` script |
| Retrain the ML model | `export_v2_model.py` → regenerates `model_output/` |
| Modify email alert templates | `backend/app/soar_email.py` |
